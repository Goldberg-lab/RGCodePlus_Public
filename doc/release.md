# RGCode+ 0.2.0

## New features
- Added 3-ring 4-quadrant concentric circle density maps for RGC quantification.
- Added custom starting angle rotation to align with tissue cuts.
- Added automatic export for raw TIFFs, annotated PNGs, and CSV density metrics.
